# Фокус+ и Firebase

## Сейчас: без входа по паролю

Кабинет открывается сразу (как раньше).  
Облако Firebase нужно только чтобы **телефон и ПК** видели одни записи и клиенты могли записаться по ссылке.

**API Key** нужен был только для входа email/пароль. Сейчас вход выключен — ключ не используется.

## Firebase бесплатный?

Да. План **Spark (бесплатный)** хватает для личного календаря фотографа (записи, синхронизация).  
Платить нужно только при очень больших объёмах — вам это не грозит.

## Правила (Realtime Database → Rules → Publish)

Если включали «только с паролем» — верните так:

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "focus": {
      "$code": {
        ".read": true,
        ".write": true
      }
    },
    "v2": {
      "focus": {
        "$code": {
          "admin": { ".read": true, ".write": true },
          "public": { ".read": true, ".write": true }
        }
      }
    }
  }
}
```

Корень базы закрыт; доступ только к вашему коду синхронизации.

## Если снова захотите вход фотографа

1. В `js/cloud-config.js` поставьте `requireAuth: true`
2. Authentication → Email/Password → пользователь
3. Rules с `"auth != null"` для `admin` (см. историю чата)
